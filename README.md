# LibrasHub organizado

Código original reorganizado por responsabilidade, sem mudança intencional de visual ou fluxo.

## Uso

1. Copie as pastas `src` e `assets`, além de `App.tsx` e `index.ts`, para a raiz do projeto Expo existente.
2. Mantenha o `package.json` atual do seu projeto.
3. Confirme as dependências `expo`, `react-native-safe-area-context` e `@expo/vector-icons`.
4. Ajuste `API_URL` em `src/api/api.ts` para o IPv4 do computador com XAMPP.
5. Rode `npx expo start -c`.

Os módulos de API estão preparados, mas ainda não foram ligados aos botões para preservar o comportamento original até os endpoints PHP existirem.
